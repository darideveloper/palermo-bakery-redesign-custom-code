# Design: Increase Modal Button Size

## Approach

The changes are entirely CSS-based, targeting the existing DOM structure generated by the WooCommerce `prettyPhoto` lightbox and our custom scripts.
We will modify the `.my-custom-lightbox-btn` and `.my-custom-fav-btn` class styles when they appear within the modal. Specifically, we target their IDs `#lightbox-share-btn` and `#lightbox-fav-btn` to ensure our overrides don't break the gallery grid buttons.

## CSS Implementation

1. **Size Increases:**
   In `src/features/gallery/product-gallery.css`, we will explicitly define width, height, and font-size for both modal button IDs.
   - `#lightbox-share-btn`
   - `#lightbox-fav-btn`
   - We will use `!important` tags where necessary to override the inline styles or generic `.my-custom-fav-btn` styles.

2. **Tooltip Implementation:**
   To avoid adding more JS elements, we will use a CSS pseudo-element (`::after`) on `#lightbox-share-btn`. 
   - `content: "Copy Link"`
   - `position: absolute; bottom: calc(100% + 10px)`
   - Reveal using opacity/visibility transition on `#lightbox-share-btn:hover::after`.
   - Ensure `#lightbox-share-btn` has `position: relative` so the tooltip is anchored correctly.
